- 🔸 **JWT 직접 발급/검증**, Access/Refresh 분리, HttpOnly + SameSite 쿠키 전략, **Stateless + RBAC** 인증 구조 확립

- 🔸 Actuator + Prometheus 연동으로 운영 메트릭 실시간 모니터링 기반 마련

> **⚡ 성능 최적화 성과 — 대용량 다운로드 쿼리 구조 개선**

| 대상 | Before | After | 개선율 |
|------|--------|-------|--------|
| 설문 응답 CSV 다운로드 | 2,402 Queries | **4 Queries** | **▼ 99.8%** |
| 설문 파일 ZIP 다운로드 | 32 Queries | **3 Queries** | **▼ 90.6%** |

N+1 문제와 반복 조회를 식별해 **IN 배치 조회 · 인덱스 튜닝**으로 SQL 라운드트립을 대폭 단축, 서버 부하와 대기 시간을 획기적으로 절감했습니다.
